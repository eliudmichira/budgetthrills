How to set up email without a domain (Brevo, free, 300 a day)
  1. Create a free account at brevo.com.
  2. Senders & IPs → Senders → Add a sender. Use the address you will send from (your Gmail is fine) and click the verification link Brevo emails you.
  3. SMTP & API → API Keys → Generate a new API key.
  4. In functions/.env set BREVO_API_KEY and EMAIL_FROM (the verified address), then firebase deploy --only functions.
  5. Press "Send test email to me" above. Resend or SendGrid work the same way with their own key.
